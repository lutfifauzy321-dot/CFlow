# Cflow

Kerangka aplikasi pelacak keuangan pribadi menggunakan Next.js 15, TypeScript,
Tailwind CSS, dan Supabase.

## Persiapan

1. Pasang dependensi dengan `npm install`.
2. Salin `.env.local.example` menjadi `.env.local`.
3. Isi URL proyek Supabase dan anon key pada `.env.local`.
4. Jalankan migrasi `supabase/migrations/001_init.sql` pada proyek Supabase.
5. Jalankan aplikasi dengan `npm run dev`.

Route, komponen, service, action, dan hook saat ini berupa stub untuk tahap
scaffolding.
